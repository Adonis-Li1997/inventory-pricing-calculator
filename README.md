# 库存处理决策计算器

一个纯前端的单件库存决策工具，帮你判断：**压在仓库的货，是现在降价卖掉止损，还是继续持有等涨价更划算。**

## 特点

- 🖱️ 纯前端，浏览器打开即用，无需安装
- 📱 响应式布局，手机电脑都能用
- 📊 双维度决策：概率期望判断 + 仓租死线提醒
- 📦 内置得物阶梯仓租费率，输入入库日期自动算仓租
- 💾 输入自动缓存，刷新不丢失
- 🔄 一键重置所有数据

## 使用方法

直接用浏览器打开 `index.html` 即可。

```bash
# macOS
open index.html

# 或者直接双击文件
```

## 输入参数说明

### 基础参数

| 参数 | 说明 |
|------|------|
| 进货成本 | 单件拿货价（元） |
| 入库运费 | 发到仓库的运费，摊到单件（元），没有就填 0 |
| 当前可售价 | 现在挂出去马上能卖掉的价格（元） |

### 仓储信息

| 参数 | 说明 |
|------|------|
| 入库日期 | 货到仓库的日期，用于自动计算库龄 |
| 商品体积档位 | 小件（≤0.005m³）/ 中件（0.005~0.02m³）/ 大件（>0.02m³），对应不同的仓租费率 |
| 最大可接受亏损比例 | 一件货最多亏总成本的百分之多少就止损（默认 5%），用于自动计算仓租死线 |

### 涨价预期参数

| 参数 | 说明 |
|------|------|
| 预期涨价后价格 | 你判断未来能涨到的价格（元） |
| 预期等待天数 | 估计还要等多少天才能涨到目标价（天） |
| 涨价把握 | 你对涨价判断的信心程度（0%~100%），建议结合历史价格趋势和节日情况判断 |

## 输出内容

### 决策结论卡

- 🟢 **建议持有** / 🔴 **建议现在就卖** —— 直接给结论
- 一句话解释原因（期望收益对比）

### 关键数据

- 当前库龄 + 所处阶段（免费期/标准费率/高费率）
- 已付仓租（按阶梯费率实际累加）
- 到今天总盈亏（当前售价 − 总成本 − 已付仓租）
- 现在卖盈亏（不含仓租）
- 持有期望盈亏（按涨价概率加权）
- 等待期仓租（预期等待天数的仓租成本，按阶梯算）
- 按概率推算最多能等多少天
- 仓租死线（按阶梯费率累加，达到亏损比例的那一天）
- 至少要涨到多少钱才值得等

### 死线提醒

根据已压仓天数和死线的关系：
- ✅ 安全：还早
- ⏰ 注意：剩 7 天以内
- ⚠️ 危险：已超过死线，注意止损

> **重要**：死线只是从「仓租」角度的提醒，不会推翻核心决策结论。最终是否止损需要你结合实际情况判断。

### 情景对比表

自动计算再持有 **7天 / 15天 / 30天 / 45天 / 60天 / 90天** 的结果：
- 总库龄
- 等待期仓租
- 累计总仓租
- 涨到目标价的盈亏
- 没涨到的亏损
- 期望盈亏（概率加权）
- 值不值得等

## 仓租计费规则（dewu）

| 库龄阶段 | 小件 ≤0.005m³ | 中件 0.005~0.02m³ | 大件 >0.02m³ |
|---------|-------------|----------------|------------|
| 第 1 ~ 35 天 | 免费 | 免费 | 免费 |
| 第 36 ~ 90 天 | 0.15元/天 | 0.20元/天 | 0.30元/天 |
| 第 91 天起 | 0.45元/天 | 0.50元/天 | 0.75元/天 |

- 前 35 天免仓租
- 第 36 天起开始计费，至第 90 天为标准费率
- 第 91 天起费率跳涨约 3 倍

## 决策逻辑

### 成本计算

```
总成本 = 进货成本 + 入库运费
```

> 所有盈亏、利润率、死线计算，都以「总成本」为基准，更贴近真实成本。

### 核心决策公式（持有 vs 抛售）

```
持有是否划算 = 涨价概率 × 涨价幅度  vs  等待期间仓租成本

涨价概率 × 涨价幅度 > 等待期间仓租成本  →  持有
否则  →  现在就卖
```

> 等待期间仓租成本按阶梯费率实际计算，不是简单的「日租 × 天数」。

### 仓租死线（纯仓租角度的提醒）

```
从入库第1天起按阶梯费率累加仓租
累计仓租达到 「总成本 × 最大亏损比例」 的那一天 = 仓租死线
```

> **死线的含义**：光算仓租的话，最多能扛多少天，就达到你设定的亏损比例底线了。
>
> 它和当前总盈亏（涨跌亏赚）没有关系，只是从「仓租成本」这一个维度给你提个醒，防止不知不觉仓租交太多。

### 两个逻辑的关系

| 情况 | 结果 |
|------|------|
| 核心决策说"值得等" + 还没死线 | ✅ 放心持有 |
| 核心决策说"不值得等" | 🔴 现在就卖（不管死线） |
| 核心决策说"值得等" 但 已超过死线 | ⚠️ 理论上值得，但仓租扛了挺久了，自己拍板 |

两个维度互相独立，不是"且"的关系。死线是保险绳，不是自动触发器。

## 其他功能

## 适用场景

- 得物 / 球鞋 / 潮玩等有价格波动的囤货
- 节日性、季节性商品的囤货决策
- 任何"持有有成本、价格有波动"的单件商品决策

## 参数调整建议

根据你的商品类型调整「最大可接受亏损比例」：

| 商品类型 | 建议比例 | 说明 |
|---------|---------|------|
| 薄利快销品（利润<10元） | 5% ~ 10% | 仓租很快吃光利润，不能等太久 |
| 普通鞋服（利润20-50元） | 15% ~ 25% | 适中 |
| 高利润限量款（利润>100元） | 30% ~ 50% | 仓租占比小，可以多等等 |
| 有明确节日周期的 | 自定义 | 节日前 7 天就是事实上的死线 |
